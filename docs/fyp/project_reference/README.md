# FYP Project Reference

This directory stores project-design material that belongs with the SMA
knowledge-graph repository rather than with the university submission folder.

`毕设总体结构-贾欧妮.pdf` is the source project blueprint. Its red annotations
identify four planned innovation modules:

1. evidence validation;
2. GraphRAG;
3. citation validation; and
4. claim-evidence validation.

Their verified implementation status and reporting rules are tracked in
`docs/FYP_REPORT_EVIDENCE_NOTES.md`.

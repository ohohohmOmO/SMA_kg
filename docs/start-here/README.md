# Start Here

这个目录集中保存每次开始工作、恢复上下文或排查问题时需要阅读的资料。
不要再从仓库各处拼凑当前状态。

## 阅读顺序

1. `PLAN.md`：运行前检查点、当前状态、canonical 输出与开放决策。
2. `AGENT_GUIDE.md`：仓库操作、环境、密钥、分支和提交规则。
3. `PROJECT_OVERVIEW.md`：项目结构、流水线命令和当前输出。
4. `docs/start-here/CONTEXT.md`：统一的领域词汇和概念定义。
5. `PROJECT_HANDOFF_2026-06-09.md`：完整项目交接和历史状态。
6. `ISSUE_LOG.md`：仅在排查失败或异常行为前必须阅读。

当前阶段的详细验证过程位于 `../reproduction/`。设计计划位于
`../design/`，历史资料位于 `../archive/` 和 `../agents/archive/`。

根目录 `README.md` 与 `AGENTS.md` 仅作为工具可自动发现的短入口；本目录
中的文件才是完整信息源。
